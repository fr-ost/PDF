Banks, phone companies and payroll systems often send statements as password-protected PDFs. That is sensible for the journey through email, but once the file is safely on your own computer, typing the password every time you open it gets old quickly.

If you know the password, Unique PDF can save an unprotected copy in a few seconds.

## An important note first

Unique PDF only removes passwords you already know. It never guesses, cracks or bypasses passwords. If you have forgotten the password to a document, ask whoever sent it for a new copy.

## Step by step

1. **Open Unlock PDF** from the Unique PDF quick menu or the Security section.
2. **Add the protected PDF.** Unique PDF asks for the password.
3. **Type the password** and press Enter. If it is wrong, you can simply try again.
4. **Click Remove password** and download the unprotected copy.

The original protected file is left as it is, so you can keep it as a backup.

## Files that open without a password but are restricted

Some PDFs open freely but do not allow printing, copying or editing. These restrictions are set with a separate permissions password, sometimes called the owner password. Unique PDF shows these restrictions when you add the file, and removes them when you enter the owner password.

Without that password, Unique PDF keeps the author's restrictions in place, even when you use the file in other tools. That respects the choice of whoever created the document.

## Using protected files in other tools

You do not always need to unlock a file first. When you add a password-protected PDF to any Unique PDF tool — merge, compress, sign, chat with PDF and more — it asks for the password once and then lets you work with the document.

## Is it safe?

Yes. The password is used only in memory for the task you asked for, and it is never saved or sent anywhere. The document itself is processed on your own computer and never uploaded.

## A tip for statements

If you keep many protected statements, unlock them once and store the unprotected copies in an encrypted folder or a password-protected archive. You get easy access on your own computer while the files stay protected if your laptop is lost.
