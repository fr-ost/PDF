# Unique PDF website

Static site generated by `npm run website` from `scripts/website/`. Do not edit these files by hand.

Deploy: import the repository in Vercel and set the **Root Directory** to `website` (framework preset: Other, no build command).

Before going live, set the site address and the Chrome Web Store link in `scripts/website/config.mjs` (or run `SITE_URL=https://your.domain STORE_URL=https://chromewebstore.google.com/detail/… npm run website`) and commit the regenerated folder.
